# Página de prueba de muestra

Utilice esta página para ejecutar pruebas de extremo a extremo en la canalización de automatización. Intencionalmente mantiene la estructura simple:

1. Una lista corta para verificar la representación de viñetas.
1. Un enlace en línea a [Documentos de Tanssi](https://docs.tanssi.network/){target=\_blank}.
1. Párrafos de texto sin formato que se pueden traducir sin tocar las plantillas.

Siéntase libre de reemplazar este archivo una vez que tenga material fuente real en inglés listo.
