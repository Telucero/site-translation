# Inicio de la documentación de prueba

Este directorio es un marcador de posición que se utiliza para verificar el nuevo flujo de contenido en inglés antes de que comiencen las traducciones. Puede reemplazar de forma segura esta sección con documentación real una vez que se valide el flujo de trabajo.

## Qué esperar

- Front matter básico de Markdown para que las tuberías de localization puedan leer los metadatos.
- Títulos y párrafos simples para confirmar que el formato se mantiene intacto.
- Enlaces a contenido de muestra adicional dentro de este directorio.
