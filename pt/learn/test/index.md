# Página Inicial da Documentação de Teste

Este diretório é um espaço reservado usado para verificar o novo fluxo de conteúdo em inglês antes que as traduções comecem. Você pode substituir com segurança esta seção por documentação real assim que o fluxo de trabalho for validado.

## O que esperar

- Front matter básico em Markdown para que os pipelines de localização possam ler os metadados.
- Títulos e parágrafos simples para confirmar que a formatação permanece intacta.
- Links para conteúdo de amostra adicional dentro deste diretório.
