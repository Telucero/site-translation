# Página de Teste de Amostra

Use esta página para executar testes de ponta a ponta no pipeline de automação. Ele intencionalmente mantém a estrutura simples:

1. Uma lista curta para verificar a renderização de marcadores.
1. Um link embutido para [Documentos Tanssi](https://docs.tanssi.network/){target=\_blank}.
1. Parágrafos de texto simples que podem ser traduzidos sem tocar nos modelos.

Sinta-se à vontade para substituir este arquivo assim que tiver material de origem em inglês real pronto.
